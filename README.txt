CUSTOMER VISIT REPORTS

Read README.md for setup and operating instructions.

Before first use: create and confirm your shared login in Supabase Auth,
disable public signups, and paste supabase/setup.sql into the SQL Editor.
Replace YOUR_LOGIN_EMAIL with your email inside the SQL Editor only, keeping
the surrounding quotes, then run it. Do not commit the filled-in SQL.
The Project URL and publishable key are configured. No secret keys or
passwords belong in the frontend.

Netlify publishes dist from GitHub main. No build command is required.

Features: shared login, 38 optional questions, Cairo Arabic font, private
photo storage, database history, date filters, XLSX export (all or range),
local drafts, old-report import, and two-page Safari-friendly PDFs.
